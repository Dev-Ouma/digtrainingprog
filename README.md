# Digitisation Training Guide — Open University of Kenya

Induction and reference site for the Directorate of ICT digitisation programme
(4.2 semester undergraduate courses).

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Six-session induction guide: roadmap, module anatomy, practice checklist, QA standards, FAQs |
| `fullprog.html` | The full ten-day workshop programme (3–12 August 2026, Lake Naivasha Resort) |

## Built with

Static HTML/CSS/JS — no build step. Bootstrap 5, Font Awesome 6 and AOS are
loaded from CDN; everything else is local.

## Features

- Light/dark theme with system preference detection and persistence
- Site-wide search (`/` or `⌘K`) across headings, content, FAQs and module anatomy
- Interactive module-anatomy pathway, practice checklist with progress tracking
- Responsive, WCAG-AA contrast, reduced-motion and print stylesheets

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
